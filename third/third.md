Классы `Reader` и `Writer` были добавлены в Java для работы с **символьными данными** (текстом), в то время как `InputStream` и `OutputStream` работают с **байтовыми данными**.

**Основные причины создания отдельных иерархий:**

1. **Кодировка символов** - Reader/Writer автоматически обрабатывают преобразование между байтами и символами с учетом кодировки
2. **Поддержка Unicode** - Reader/Writer корректно работают с многобайтовыми кодировками (UTF-8, UTF-16)
3. **Удобство работы с текстом** - методы для чтения/записи строк, символов, массивов символов
4. **Автоматическое преобразование** - не нужно вручную конвертировать байты в символы и обратно

**Аналогия:**
- InputStream/OutputStream - работа с "сырыми" байтами (любые данные)
- Reader/Writer - работа с текстом (символами)

Без Reader/Writer пришлось бы вручную управлять кодировками при работе с текстовыми данными, что сложно и подвержено ошибкам.
