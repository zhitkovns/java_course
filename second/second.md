Метод `flush()` нужен для **принудительной записи данных из буфера в конечный пункт назначения**.

**Зачем это нужно:**
1. **Буферизация вывода** - многие классы ввода-вывода (FileWriter, PrintWriter, OutputStream и др.) используют буфер для оптимизации, накапливая данные перед записью
2. **Принудительная запись** - `flush()` заставляет немедленно записать все данные из буфера, даже если он еще не заполнен
3. **Важные сценарии использования:**
```java
// Пример с FileWriter
FileWriter writer = new FileWriter("output.txt");
writer.write("Важные данные");

// Без flush() данные могут остаться в буфере и не записаться в файл
writer.flush(); // Гарантированная запись в файл

// Пример с сетевым соединением
OutputStream output = socket.getOutputStream();
output.write(data);
output.flush(); // Немедленная отправка данных по сети
```

**Когда особенно важен flush():**
- При работе с файлами, чтобы гарантировать запись критически важных данных
- В сетевых приложениях для немедленной отправки данных
- При отладке, чтобы увидеть вывод в реальном времени
- Перед закрытием ресурсов

**Без flush()** данные могут оставаться в буфере неопределенное время и быть потеряны при аварийном завершении программы.
