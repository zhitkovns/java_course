**Классы исключений и их назначение:**

**Throwable** - базовый класс для всех исключений и ошибок в Java. Содержит методы для получения информации об исключении (getMessage(), getStackTrace()).

**Error** - непроверяемые исключения, указывающие на серьезные проблемы, которые приложение не должно пытаться обрабатывать. Примеры:
- OutOfMemoryError - нехватка памяти
- StackOverflowError - переполнение стека
- VirtualMachineError - ошибки виртуальной машины

**Exception** - базовый класс для проверяемых исключений, которые должны быть обработаны в коде. Примеры:
- IOException - ошибки ввода-вывода
- SQLException - ошибки работы с базой данных
- ClassNotFoundException - класс не найден

**RuntimeException** - непроверяемые исключения (unchecked), которые обычно указывают на ошибки программирования. Не требуют обязательной обработки. Примеры:
- NullPointerException - обращение к null ссылке
- IllegalArgumentException - неверный аргумент метода
- ArrayIndexOutOfBoundsException - выход за границы массива
- ArithmeticException - арифметическая ошибка (деление на ноль)

**Основное различие:** Error и RuntimeException - непроверяемые, Exception (кроме его RuntimeException подклассов) - проверяемые исключения.
