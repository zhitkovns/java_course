# Huffman Coding Implementation

Реализация алгоритма кодирования-декодирования по методу Хаффмана с оптимизированным бинарным форматом.

#### Требования к программе:
Программа полностью управляется из командной строки, умеет кодировать и декодировать файлы через аргументы.
В качестве тестовых примеров для кодирования подготовлены:
1. Текстовый файл состоящих из 10 одинаковых символов. Например, "1111111111".
2. Текстовый файл длины 20 байт, состоящий из 3-х различных символов, каждый из которых встречается 10, 5 и 5 раз. Например, "11111111112222233333".
3. Бинарный файл, в который скомпилируется ваша программа, т.е. результирующий class-файл

## Сборка

```bash
javac -encoding UTF-8 HuffmanCoding.java
```

## Запуск

### Кодирование файла
```bash
java HuffmanCoding -c inputFile [outputFile]
```
Здесь `[outputFile]` означает, что ввод имени закодированного файла опционален. 
Программа при отсутствии этого аргумента автоматически создаст имя файла как `inputFile.huff`.

### Декодирование файла  
```bash
java HuffmanCoding -d inputFile [outputFile]
```
Здесь `[outputFile]` означает, что ввод имени раскодированного файла опционален. 
Программа при отсутствии этого аргумента автоматически создаст имя файла с оригинальным расширением, например `inputFile_decoded.txt` или `inputFile_decoded.class`.

## Форматы файлов
### Кодирование:
#### Входные данные:
- Любой файл (текстовый или бинарный)

#### Выходные данные:
- **Файл .huff**: Бинарный файл, содержащий:
  - Оригинальное расширение файла
  - Таблицу кодирования Хаффмана в компактном формате
  - Закодированные данные
  - Всю информацию, необходимую для декодирования

### Декодирование:
#### Входные данные:
- **Файл .huff**: Закодированный файл

#### Входные данные:
- Восстановленный исходный файл с оригинальным расширением

## Структура .huff файла

.huff файл имеет оптимизированный бинарный формат и содержит:

```
[1 байт: флаги]              - бит 0: наличие расширения, бит 1: специальный формат для 1 символа, бит 2: большая таблица (>255)
[0-255 байт: расширение]     - только если есть расширение: длина + данные
[1-2 байта: размер таблицы]  - 1 байт для таблиц ≤255, 2 байта для больших таблиц
[Таблица кодов:
    [1 байт: символ]         - исходный байт
    [1-2 байта: длина кода]  - длина кода Хаффмана в битах
    [байты кода]             - код Хаффмана в бинарном формате (выровненный до байта)
]
[1-4 байта: L]               - длина закодированных данных в битах
[байты данных]               - закодированные данные (выровненные до байта)
```

### Особые случаи:
- **Один символ**: компактный формат - только символ и количество повторений
- **Малые таблицы** (≤255 символов): используются 1-байтовые поля
- **Большие таблицы** (>255 символов): используются 2-байтовые поля

## Тестовые примеры

### 1. Файл с 10 одинаковых символов
**test1.txt**: `1111111111`
- **Результат**: высокая степень сжатия благодаря специальному формату для одного символа

### 2. Файл длины 20 байт с частотами 10, 5, 5
**test2.txt**: `11111111112222233333`
- **Результат**: эффективное кодирование для малого алфавита

### 3. Бинарный файл
**HuffmanCoding.class** - скомпилированный class-файл
- **Результат**: поддержка полного набора символов (0-255) через расширенный формат таблицы

## Примеры использования

```bash
# Компиляция
javac -encoding UTF-8 HuffmanCoding.java

# Кодирование тестовых файлов
java HuffmanCoding -c test1.txt
java HuffmanCoding -c test2.txt
java HuffmanCoding -c HuffmanCoding.class

# Декодирование (автоматически восстанавливаются оригинальные расширения)
java HuffmanCoding -d test1.huff         # создаст test1_decoded.txt
java HuffmanCoding -d test2.huff         # создаст test2_decoded.txt
java HuffmanCoding -d HuffmanCoding.huff # создаст HuffmanCoding_decoded.class
```

## Особенности реализации

- **Компактный формат**: оптимизированное хранение для малых файлов и таблиц
- **Автоматическое определение формата**: программа выбирает оптимальный формат хранения
- **Проверка целостности**: встроенная проверка корректности кодирования/декодирования
- **Поддержка всех типов файлов**: текстовые и бинарные файлы любой сложности
